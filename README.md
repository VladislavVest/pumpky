# Pumpky

Атмосферный таск-трекер для Windows.

## Скачать и установить

Перейди в раздел **[Releases](https://github.com/VladislavVest/pumpky/releases)** и скачай нужный вариант из последнего релиза:

* **`Pumpky.Setup.1.0.0.exe`** — установщик (рекомендуемый вариант: добавляет ярлык и поддерживает автоматические обновления с GitHub).
* **`Pumpky.1.0.0.exe`** — портативная версия (запускается сразу без установки).

### Если Windows блокирует запуск
Так как сборка не подписана платным сертификатом разработчика, при первом запуске Windows SmartScreen может показать предупреждение *«Windows защитила ваш ПК»*. Нажми **«Подробнее»** -> **«Всё равно выполнить»**.

## Автообновления
При установке через `Pumpky Setup` приложение проверяет новые релизы на GitHub и может обновляться при выходе следующих версий.
